 🪐 Planet Clicker (MVP)

Кликер с архитектурой, построенной на паттерне MVP (Model-View-Presenter).

## 📖 Описание

Прототип показывает использование архитектурного паттерна MVP для управления логикой и UI.

## ✨ Особенности
- MVP архитектура
- Базовая кликерная механика
- Простая UI-система
- Zenject для управления зависимостями
