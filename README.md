# 🎮 Платформер 2D (Zenject)

2D платформер с компонентным подходом и внедрением зависимостей через Zenject.

## 📖 Описание

Прототип создан для отработки компонентной архитектуры и внедрения зависимостей в Unity.

## ✨ Особенности
- Zenject для управления зависимостями
- Механика движения и прыжков персонажа
- Простая 2D-графика
