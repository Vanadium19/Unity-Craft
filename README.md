# 💾 Сервис сохранений с AES шифрованием

Сервис для удалённого сохранения данных с использованием шифрования AES.

## 📖 Описание

Прототип системы удалённых сохранений с безопасным хранением данных.

## ✨ Особенности
- Шифрование данных с помощью AES
- Простое API для интеграции в игры
- Отправка и загрузка сохранений на сервер
